# Gabor Patch 視覺訓練

一個純前端（HTML + CSS + JavaScript，無後端、無資料庫）的視覺訓練網頁工具，
在一般 LCD/OLED 螢幕上，以短暫閃現 Gabor patch（高斯包絡的條紋圖樣）的方式，
協助散光（方向辨別）與對比敏感度（類近視訓練）的練習。介面採高對比、
文字 + 符號回饋設計，對色弱使用者友善。

> 本工具僅為視覺訓練輔助用途，不能取代驗光或醫療診斷，訓練時請配戴合適的
> 矯正眼鏡（散光訓練需要含散光度數的眼鏡）。

## 這個 project 在做什麼

- **散光方向辨別訓練**：先短暫閃現「基準方向」，再閃現「略為偏轉」的條紋，
  受試者判斷是順時針偏還是逆時針偏。
- **對比敏感度訓練**：在畫面左側或右側短暫閃現低對比度的圖樣，判斷出現在
  哪一側。
- **眼別模式**：右眼 / 左眼 / 雙眼 / 雙眼輪替（訓練過程中會自動在過半時間
  提示遮眼並切換）。
- **難度模式**：
  - 手動難度（固定的角度差 / 對比度，分級預設值）。
  - 自動難度（階梯法 staircase：方向辨別用 2-down-1-up 收斂至約 70.7%
    正確率；對比敏感度用 3-down-1-up 收斂至約 79.4% 正確率）。
- **倒數計時訓練、鍵盤方向鍵作答、每日訓練量追蹤、歷史紀錄（可單筆刪除）**。

## 資料是怎麼保存的

整個 App **沒有伺服器、沒有帳號系統**，所有資料都只存在使用者自己瀏覽器的
`localStorage`，以 JSON 格式儲存在以下三組 key：

| localStorage key      | 內容                                             | 何時寫入                      |
|-----------------------|--------------------------------------------------|-------------------------------|
| `gaborTrainingHistory` | 每次訓練的紀錄（時間、眼別、模式、正確率等）     | 每次訓練正常/中斷結束時新增一筆 |
| `gaborThresholds`      | 自動難度各條 staircase 的完整收斂狀態（見下方） | 只有「正常跑完」的訓練才會更新 |
| `gaborAxisSettings`    | 左右眼散光軸度設定值（未設定過預設為 0）       | 每次修改軸度輸入框時即時儲存   |

因為資料只存在瀏覽器本機，**換瀏覽器、換裝置、清除瀏覽器資料都會讓紀錄消失**，
且各裝置之間預設不會互通。若需要跨裝置延續，請見下方「跨裝置同步」。

## 如何利用之前的訓練成果做調整

啟用「自動難度」時，App 會記住每一條 staircase（依「眼別 × 模式」拆分，
最多 6 條：左右眼各自的方向/對比敏感度、雙眼模式的方向/對比敏感度）目前的
完整狀態 ——包含目前的角度差/對比度、連續答對次數、反轉點紀錄、上一次調整方向
——而不只是存最後一個數字。

- **下次開始會接續上次的難度**，不會每次都從預設值（15°／50% 對比）重新
  暖身，對短時間（3-5 分鐘）的訓練特別重要，因為單一條 staircase 在一次
  session 裡往往湊不滿幾次反轉，需要靠跨 session 累積才能逐漸逼近真正的
  閾值。
- **只有「正常跑完」整個訓練的 session 才會回寫難度狀態**；若用「結束訓練」
  按鈕中途中斷，則本次資料視為不可靠，**不會覆蓋已儲存的難度**，避免被打擾
  / 誤按造成的異常資料污染長期收斂結果。
- 難度會各自獨立收斂（例如右眼方向辨別、左眼對比敏感度各自累積自己的
  reversals），彼此不互相影響。
- 若想重新從預設值開始，目前沒有內建的「重設難度」按鈕，可自行在瀏覽器
  開發者工具執行 `localStorage.removeItem('gaborThresholds')`。

## 跨裝置同步（文字碼，無加密）

頁面最下方「跨裝置同步（文字碼）」區塊可以把 `gaborAxisSettings` 和
`gaborThresholds`（軸度設定 + 難度收斂狀態，**不含歷史紀錄**，避免同步碼過長）
打包成一段 JSON 文字：

1. 在來源裝置按「產生同步碼」→「複製」。
2. 把文字貼到另一台裝置的匯入欄位，按「匯入同步碼」即可套用（會覆蓋目前
   設定前再次確認）。

> 此文字碼**沒有加密**，內容是明文 JSON，只包含軸度與難度數字，不含任何
> 個資。若要透過聊天工具、雲端硬碟等第三方管道傳遞，請自行評估該管道的
> 外洩風險。

## 使用方式

純靜態網頁，用任何本機伺服器或靜態網站託管（例如 GitHub Pages）皆可開啟
`index.html`：

```bash
python -m http.server 8000
# 瀏覽器開啟 http://localhost:8000/index.html
```

## 檔案結構

- `index.html` — 畫面結構（設定／遮眼／訓練／總結／歷史紀錄／跨裝置同步）
- `app.js` — 所有邏輯（狀態機、Gabor 圖樣繪製、staircase 演算法、
  localStorage 讀寫、跨裝置同步）
- `style.css` — 樣式（高對比、色弱友善、訓練畫面單頁塞滿視窗）
